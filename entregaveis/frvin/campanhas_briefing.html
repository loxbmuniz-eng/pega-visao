O projeto que gera os vídeos, as duas campanhas que rodaram nele, o que ficou pendente e o que mudou desde que o material foi feito.

Os vídeos nunca estiveram no repositório

O .gitignore do estúdio ignora saida/, *.mp4 e *.webm. Foi versionado o código que gera os vídeos — as cenas e os dados de cada campanha —, nunca os arquivos renderizados. Quando o container daquela sessão foi reciclado, os MP4 foram junto.

Não é perda: o render é determinístico de propósito. Rodei os três de novo agora, e eles saem idênticos ao que saiu lá.

O estúdio, em uma passada

O vídeo é uma página HTML. O renderizador é dono do relógio — a cena não anima sozinha, e animation e transition do CSS estão desligados à força. É isso que faz o quadro 47 ser o quadro 47 em qualquer máquina: o vídeo entregue é o vídeo aprovado, não uma gravação de tela que pulou quadro. Zero dependências — Node e Chromium, nada de npm.

# uma campanha vira vídeo assim
./estudio renderizar carrossel \
  --dados exemplos/frvin_last_dance.json \
  --formato mp4

# trocar copy = editar o JSON e rodar de novo
# nenhuma arte é redesenhada; a identidade vem do próprio dado
